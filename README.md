Containerlab project files.
- frr-spineleaf - A spine and leaf topology using with a single tenant. BGP unnumbered is used for the underlay, and BGP with VXLAN/EVPN for the overlay. The borderleaf and inet nodes provide access to the Internet.
- srlinux-clos - A spine and leaf topology using Nokia SR Linux. The topology contains two spines switches, three leaf switches and three clients connected to the leaf switches. The text files contain the commands to configure each of the switches.
